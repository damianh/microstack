# Acknowledgements

MicroStack is a .NET port of [MiniStack](https://github.com/damianh/ministack), a
Python-based local AWS service emulator. The service behaviours, API surface, and test
coverage in MicroStack were derived from the MiniStack codebase. Provenance comments
throughout the source reference the original Python modules and test files.
